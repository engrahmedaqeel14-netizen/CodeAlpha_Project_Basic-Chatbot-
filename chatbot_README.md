# PyBot - Rule-Based Chatbot 🤖

A simple interactive chatbot built in Python using if-elif, functions, loops, and input/output.

## How to Run

### Terminal:
```bash
python chatbot.py
```

### VS Code:
Press **F5** → "Run PyBot Chatbot"

## Supported Commands

| You say              | PyBot replies                  |
|----------------------|-------------------------------|
| hello / hi / hey     | Greeting response             |
| how are you          | Status response               |
| what is your name    | Bot introduction              |
| tell me a joke       | Random programmer joke        |
| what time is it      | Current system time           |
| today / date         | Current date                  |
| help                 | Lists all commands            |
| thanks               | You're welcome!               |
| bad / sad / upset    | Empathetic response           |
| good / great / fine  | Happy response                |
| bye / goodbye / exit | Ends the chat                 |

## Concepts Used
- `if-elif-else` — rule matching logic
- `functions` — get_response(), chat(), print_banner()
- `while loop` — keeps chat running
- `input/output` — user interaction
- `random` — random joke selection
- `datetime` — live time and date
